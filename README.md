## 🤔 Почему Zametki?

Большинство приложений для заметок по умолчанию синхронизируют ваши данные с облаком. Zametki придерживается иного подхода: ваши заметки остаются на вашем устройстве. Приложение создано специально для тех, кто ценит конфиденциальность, простоту, работу офлайн и отсутствие отвлекающих факторов. Никаких аккаунтов, подписок или фоновых серверов. Только чистый, быстрый интерфейс для записи лекций, идей и повседневных задач в любое время и в любом месте.

1. ✅ **100% локальное хранилище** – заметки сохраняются непосредственно в вашем браузере
2. 🔒 **Конфиденциален по умолчанию** – данные не покидают ваше устройство
3. 🌐 **Работает оффлайн** – подключение к интернету не требуется
4. 👤 **Удобный интерфейс** – легковесное приложение без отвлекающих элементов
5. 🔐 **Храните секреты** - создайте секретную заметку и не волнуйтесь о ваших секретах
6. 📌 **Прикрепите заметку** - любую заметку всегда можно закрепить, чтобы не потерять в дальнейшем
7. ✏️ **Выберите цвет** - важность заметки можно выбрать цветом

## 😸 С запуском справиться даже котёнок!

Zametki работает полностью в вашем браузере, а интерфейс прост и понятен в обращении, поэтому пользоваться сможет кто угодно. Просто откройте сайт и начните работать. Ничего лишнего!

## 👀 Как пользоваться?

1. **Откройте приложение** – перейдите по ссылке [Zametka](https://izametka.github.io/Zametka/).
2. **Начните писать** – создавайте, редактируйте и организуйте свои заметки.
3. **Сохранение автоматически** – все изменения мгновенно сохраняются в локальном хранилище вашей базы данных.
4. **Доступ в любое время** – перезагрузите страницу или работайте офлайн; ваши заметки будут именно там, где вы их оставили.
5. **Сделайте тег** - назначьте вашей заметке тег по своему желанию и легко структурируйте ваши записи 
6. **Удобный поиск** - поле поиска позволяет легко найти любую вашу заметку, как по тегам, так и по тексту
7. **Создайте секретную заметку** - нажмите на букву t в названии "Zametki", сохраните ваши секреты
