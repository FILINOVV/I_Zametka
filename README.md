## 🤔 Почему Zametki?

Большинство приложений для заметок по умолчанию синхронизируют ваши данные с облаком. Zametki придерживается иного подхода: ваши заметки остаются на вашем устройстве. Приложение создано специально для тех, кто ценит конфиденциальность, простоту, работу офлайн и отсутствие отвлекающих факторов. Никаких аккаунтов, подписок или фоновых серверов. Только чистый, быстрый интерфейс для записи лекций, идей и повседневных задач в любое время и в любом месте.

✅ **100% локальное хранилище** – заметки сохраняются непосредственно в вашем браузере
🔒 **Конфиденциален по умолчанию** – данные не покидают ваше устройство
🌐 **Работает оффлайн** – подключение к интернету не требуется
👤 **Удобный интерфейс** – легковесное приложение без отвлекающих элементов

## 👀 Как пользоваться?

Zametki работает полностью в вашем браузере, поэтому настройка занимает мгновение:

1. **Откройте приложение** – перейдите по ссылке "LINK PLACEHOLDER".
2. **Начните писать** – создавайте, редактируйте и организуйте свои заметки.
3. **Сохранение автоматически** – все изменения мгновенно сохраняются в локальном хранилище вашей базы данных.
4. **Доступ в любое время** – перезагрузите страницу или работайте офлайн; ваши заметки будут именно там, где вы их оставили.
